# Project docs

Reference docs live in `docs/`. Before creating a new page, store link, tracked event, or campaign string, read `docs/UTM_CONVENTIONS.md` and follow it exactly: it defines campaign naming, the fixed utm parameters, and the list of tracked events. Campaign strings are never renamed once live.

# Writing style

Keep em-dashes to a minimum: use one only when strictly needed. Prefer commas, colons, or separate sentences. Applies to site copy and all other prose.
